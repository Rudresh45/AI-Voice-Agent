# Incident Response

1. Confirm alert and assign incident owner.
2. Determine impact and whether data integrity/privacy is at risk.
3. Disable affected tools or revoke credentials if necessary.
4. Preserve protected logs and audit records.
5. Roll back last release or use safe fallback.
6. Restore only from verified backups.
7. Verify tenant isolation and critical workflows before reopening.
8. Document timeline, impact, root cause and corrective actions.
